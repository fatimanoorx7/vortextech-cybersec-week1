# Vortex Tech Cyber Security Internship – Week 1

## OWASP Top 10 Vulnerabilities Research

This repository contains my **Week 1 research task** for the **Vortex Tech Cyber Security Internship – Cyber Security Track**.

### Task Overview

The objective of this task is to build a foundational understanding of common web application security risks by researching five vulnerabilities from the **OWASP Top 10:2025**.

For each vulnerability, the research covers:

* A plain-language explanation
* How an attacker could exploit it
* A real-world example or case
* Practical prevention and mitigation techniques

### Vulnerabilities Covered

1. **A06:2025 – Insecure Design**
2. **A07:2025 – Authentication Failures**
3. **A08:2025 – Software or Data Integrity Failures**
4. **A09:2025 – Security Logging & Alerting Failures**
5. **A10:2025 – Mishandling of Exceptional Conditions**
